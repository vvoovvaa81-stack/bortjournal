# Бортжурнал

Дневник автомобиля для Android: заправки, ремонты, расходы, график ТО со шкалой ресурса и напоминания по пробегу и по дате.

**Скачать:** [последняя версия](../../releases/latest) → файл `Bortjournal-….apk`.

APK собирается автоматически (GitHub Actions) при каждом изменении в ветке `main`.
